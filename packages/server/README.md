# @honeypot-detector/server

REST API of [Crypto Honeypot Detector](../../README.md#api). Serves the built web app too
(`packages/webapp/dist`) when present.

```bash
npm start      # production
npm run dev    # restart on changes
npm run demo   # local anvil chain with example scam tokens
```

Configuration: environment variables, see [`.env.example`](../../.env.example).
